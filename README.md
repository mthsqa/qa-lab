# qa-lab

Laboratório pessoal de estudos em qualidade de software e automação de testes.

Objetivo: registrar fundamentos, checklists e exemplos reutilizáveis de Cypress, Playwright e teste de API.

## Stack em estudo

- Cypress (E2E web)
- Playwright (E2E web e API request)
- Testes de API (contrato, status, auth)
- Checklists de smoke, regressão e exploração
